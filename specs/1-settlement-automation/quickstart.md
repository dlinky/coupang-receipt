# Quickstart Guide: 본사 정산서 자동화 프로그램

**Date**: 2025-11-14  
**Feature**: 본사 정산서 자동화 프로그램

## 개요

본사 정산서 엑셀 파일의 데이터를 지점 정산서 양식에 자동으로 매핑하여 입력하는 데스크톱 애플리케이션입니다.

## 빠른 시작

### 1. 애플리케이션 실행

```bash
python src/main.py
```

또는 실행 파일로 패키징된 경우:

```bash
./settlement-automation
```

### 2. 기본 사용 흐름

#### 단계 1: 본사 파일 선택
1. "본사 파일 선택" 버튼 클릭
2. 본사 정산서 엑셀 파일 선택 (형식: `빅보스_부산_진구중앙_YYYY_MM-W.xlsx`)
3. 비밀번호 입력 (기본값: 4880403942, config.json에서 변경 가능)
4. "파일 로드" 버튼 클릭

#### 단계 2: 지점 파일 선택
1. "지점 파일 선택" 버튼 클릭
2. 지점 정산서 엑셀 파일 선택 (또는 자동 생성)
3. 파일 정보 확인

#### 단계 3: 주차 선택 및 실행
1. 주차 선택 (1~5주차 또는 "전체")
2. "데이터 매핑 실행" 버튼 클릭
3. 진행 상태 확인 (프로그레스 바 및 로그)
4. 완료 메시지 확인

### 3. 매핑 설정 수정

1. "매핑 설정 수정" 버튼 클릭
2. 매핑 항목 리스트 확인
3. 항목 추가/수정/삭제
4. "저장" 버튼 클릭

## 파일 구조

### 입력 파일

**본사 정산서**:
- 파일명 형식: `빅보스_부산_진구중앙_YYYY_MM-W.xlsx`
- 예시: `빅보스_부산_진구중앙_2024_11-1.xlsx` (2024년 11월 1주차)
- 비밀번호 보호 파일 지원

**지점 정산서**:
- 파일명 형식: `쿠팡 MM월 W주차 정산표.xlsx`
- 예시: `쿠팡 11월 1주차 정산표.xlsx`
- 본사 파일 정보를 기반으로 자동 생성 가능

### 설정 파일

**config/config.json**:
```json
{
  "default_password": "4880403942",
  "week_offsets": {
    "1": 0,
    "2": 36,
    "3": 72,
    "4": 108,
    "5": 144
  }
}
```

**config/mapping.json**:
매핑 규칙 설정 (GUI에서 수정 가능)

## 주요 기능

### 1. 단순 데이터 매핑
- 라이더 목록, 고용보험, 시간제보험 등 단순 복사 항목
- 본사 파일 셀 범위 → 지점 파일 셀 범위

### 2. 조건부 데이터 매핑
- 프로모션: 달성한 라이더만 프로모션 금액 입력
- 지점 파일의 라이더 목록 기준으로 매칭

### 3. 날짜 계산
- 타이틀: "MM월 W주차" 형식
- 지급일자: "YY.MM.DD" 형식 (해당 주차 금요일)
- 날짜 범위: "MM.DD ~ MM.DD" 형식 (전주 수요일 ~ 해당주 화요일)

### 4. 주차별 오프셋 처리
- 1주차: 기준 위치
- 2주차: 행 방향 +36 오프셋
- 3주차: 행 방향 +72 오프셋
- 4주차: 행 방향 +108 오프셋
- 5주차: 행 방향 +144 오프셋

### 5. 월간정산
- 모든 주차의 라이더 목록 수집
- 중복 제거하여 고유 라이더 목록 생성
- 월간정산 시트에 입력

## 에러 처리

### 파일 오류
- **비밀번호 오류**: 비밀번호를 다시 입력하세요
- **파일 없음**: 파일 경로를 확인하세요
- **파일 형식 오류**: .xlsx 형식인지 확인하세요

### 매핑 오류
- **시트 없음**: 에러 메시지 표시 후 매핑 파일(mapping.json)을 메모장으로 자동 열기
- **셀 범위 오류**: 에러 메시지 표시 후 매핑 파일을 메모장으로 자동 열기
- **데이터 형식 불일치**: 사용자에게 알림 표시

### 시스템 오류
- **메모리 부족**: 파일 크기를 확인하세요
- **권한 오류**: 파일 쓰기 권한을 확인하세요

## 성능 목표

- 단일 주차 처리: 30초 이내
- 전체 주차(5주차) 처리: 3분 이내
- 월간정산 생성: 10초 이내
- GUI 응답 시간: 1초 이내

## 문제 해결

### 문제: 파일이 열리지 않음
- 비밀번호가 올바른지 확인
- 파일이 다른 프로그램에서 열려있는지 확인
- 파일 경로에 특수문자가 없는지 확인

### 문제: 매핑이 실행되지 않음
- 본사 파일과 지점 파일이 모두 로드되었는지 확인
- 주차가 선택되었는지 확인
- 매핑 설정 파일이 올바른지 확인

### 문제: 데이터가 올바르게 입력되지 않음
- 매핑 설정을 확인하세요
- 본사 파일의 시트명과 셀 범위가 올바른지 확인
- 지점 파일의 시트명과 셀 범위가 올바른지 확인

## 다음 단계

1. **매핑 설정 커스터마이징**: `config/mapping.json` 파일을 수정하여 새로운 매핑 규칙 추가
2. **설정 파일 백업**: `config/` 디렉토리를 정기적으로 백업
3. **로그 확인**: 에러 발생 시 `logs/` 디렉토리의 로그 파일 확인
