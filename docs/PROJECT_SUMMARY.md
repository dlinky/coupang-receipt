# 본사 정산서 자동화 프로그램 - 기획서 요약

## 📋 프로젝트 개요

**프로젝트명**: 본사 정산서 자동화 프로그램 (쿠팡 정산서 프로그램)  
**개발 목적**: 본사에서 제공하는 정산서 Excel 파일의 데이터를 지점 정산서 양식에 자동으로 매핑하여 입력하는 데스크톱 애플리케이션  
**개발 기간**: 2024년 11월  
**사용 빈도**: 주당 1회 (월 4-5회)  
**대상 사용자**: 지점 정산 담당자 (비기술 사용자)

## 🎯 핵심 가치 제안

### 문제 상황
- **수동 작업의 반복성**: 매주 본사 정산서 Excel 파일에서 데이터를 복사하여 지점 정산서 양식에 수동으로 입력
- **인간 오류 가능성**: 수십 개의 데이터 항목을 수동으로 입력하면서 발생하는 실수
- **시간 소모**: 주차별로 30분~1시간 소요되는 반복 작업
- **복잡한 매핑 규칙**: 단순 복사가 아닌 조건부 복사, 합산, 날짜 계산 등 다양한 변환 로직 필요

### 해결 방안
- **완전 자동화**: 파일 선택 → 주차 선택 → 실행 버튼 클릭만으로 모든 데이터 매핑 완료
- **다양한 계산 방식 지원**: 단순 복사, 조건부 복사, 합산, 날짜 계산, 고유값 추출 등
- **설정 기반 확장성**: 코드 수정 없이 JSON 파일로 매핑 규칙 추가/수정 가능
- **오류 방지**: 자동화를 통한 입력 실수 제거

## 🚀 핵심 기능

### 1. Excel 파일 간 데이터 매핑
- 본사 정산서 Excel 파일에서 데이터 추출
- 지점 정산서 Excel 양식에 자동 입력
- 비밀번호 보호된 Excel 파일 지원
- 병합 셀 자동 감지 및 처리

### 2. 다양한 계산 방식 (Calculation Methods)

#### `simple_copy` - 단순 복사
- 본사 파일의 셀 범위에서 지점 파일로 직접 복사
- 주차별 행 오프셋 자동 적용
- 특정 항목(고용보험, 산재보험 등) 부호 반전 지원

#### `conditional_copy` - 조건부 복사
- 조건을 만족하는 경우만 데이터 복사
- 예: 프로모션 달성 여부가 "달성"인 경우만 값 입력
- 라이더명 기준 매칭

#### `simple_sum` - 단순 합산
- 여러 열(붙어있거나 떨어져 있는)의 값을 행별로 합산
- 예: 배달료 = G열 + H열 + I열 합산
- 예: 추가배달료 = K열 + M열 + O열 + Q열 합산

#### `conditional_sum` - 조건부 합산
- 조건을 만족하는 모든 행의 값을 합산
- 예: 같은 라이더가 여러 프로모션을 달성한 경우 모두 합산
- `conditional_copy`와 달리 여러 행의 값을 합산

#### `date_calculation` - 날짜 계산
- 주차 정보를 기반으로 다양한 날짜 형식 생성
  - 타이틀: "11월 1주차"
  - 지급일: "24.11.08" (해당 주차 금요일)
  - 정산기간: "11.05 ~ 11.11" (전주 화요일 ~ 해당주 월요일)

#### `unique_extraction` - 고유값 추출
- 여러 주차의 데이터에서 중복 제거하여 고유값만 추출
- 예: 월간정산 시 모든 주차의 라이더 목록에서 중복 제거

### 3. 주차별 처리
- 1~5주차 개별 선택 또는 전체 선택
- 주차별 행 오프셋 자동 적용 (1주차: 0행, 2주차: 36행, ...)
- 주차별 타이틀 및 날짜 자동 계산

### 4. 월간정산 생성
- 모든 주차 처리 후 월간정산 시트에 고유 라이더 목록 자동 입력
- 주차별 데이터 집계 지원

### 5. 사용자 친화적 GUI
- 직관적인 3단계 워크플로우: 파일 선택 → 주차 선택 → 실행
- 진행 상태 표시 (진행률, 현재 처리 중인 항목)
- 에러 발생 시 명확한 메시지 및 매핑 파일 자동 열기

## 🛠 기술 스택

### 핵심 기술
- **Python 3.11+**: 메인 개발 언어
- **PySide6**: 크로스 플랫폼 GUI 프레임워크 (Qt 기반)
- **openpyxl**: Excel 파일 읽기/쓰기
- **msoffcrypto-tool**: 비밀번호 보호된 Excel 파일 복호화
- **pytest**: 테스트 프레임워크

### 아키텍처 패턴
- **계층형 구조**: Models → Services → GUI
- **Strategy 패턴**: 계산 방식별 독립적인 처리 로직
- **설정 기반 확장성**: JSON 파일로 매핑 규칙 관리

src/

## 📊 데이터 흐름

### 처리 워크플로우
```
1. 사용자 입력
   ├─ 본사 정산서 파일 선택 (파일명에서 연도/월/주차 자동 파싱)
   ├─ 지점 정산서 파일 선택 (또는 자동 생성)
   └─ 주차 선택 (1~5주차 또는 전체)

2. 파일 검증
   ├─ 파일 존재 여부 확인
   ├─ Excel 형식 검증
   └─ 비밀번호 필요 시 입력 요청

3. 매핑 실행 (주차별 반복)
   ├─ 주차별 오프셋 계산
   ├─ 매핑 규칙별 처리 (50+ 항목)
   │   ├─ simple_copy: 단순 복사
   │   ├─ conditional_copy: 조건부 복사
   │   ├─ simple_sum: 합산
   │   ├─ conditional_sum: 조건부 합산
   │   ├─ date_calculation: 날짜 계산
   │   └─ unique_extraction: 고유값 추출
   └─ 진행 상태 업데이트

4. 결과 저장
   ├─ 지점 파일 저장 (파일명: "쿠팡 YY월 W주차 정산표.xlsx")
   └─ 완료 메시지 표시
```

## 🔧 매핑 규칙 예시

### 예시 1: 단순 복사
```json
{
  "data_name": "라이더 목록",
  "branch_sheet": "주간정산",
  "branch_range": "C6:C35",
  "head_office_sheet": "종합",
  "head_office_range": "C17:C46",
  "calculation_method": "simple_copy"
}
```

### 예시 2: 합산 (붙어있는 열)
```json
{
  "data_name": "배달료",
  "branch_sheet": "주간정산",
  "branch_range": "E6:E35",
  "head_office_sheet": "종합",
  "head_office_range": "G17:I46",
  "calculation_method": "simple_sum"
}
```

### 예시 3: 합산 (떨어져 있는 열)
```json
{
  "data_name": "추가배달료",
  "branch_sheet": "주간정산",
  "branch_range": "F6:F35",
  "head_office_sheet": "종합",
  "head_office_range": "K17:K46, M17:M46, O17:O46, Q17:Q46",
  "calculation_method": "simple_sum"
}
```

### 예시 4: 조건부 합산
```json
{
  "data_name": "지점 프로모션 합계",
  "branch_sheet": "주간정산",
  "branch_range": "H6:H35",
  "head_office_sheet": "협력사 자체 미션",
  "head_office_range": "",
  "calculation_method": "conditional_sum",
  "condition": {
    "source_sheet": "협력사 자체 미션",
    "name_column": "G",
    "value_column": "F",
    "check_column": "J",
    "check_value": "달성"
  }
}
```

## 🎨 주요 특징

### 1. 설정 기반 확장성
- 코드 수정 없이 `mapping.json` 파일만 수정하여 새로운 매핑 규칙 추가
- 계산 방식(Strategy 패턴)으로 새로운 로직 추가 용이

### 2. 오류 처리 및 사용자 경험
- 명확한 에러 메시지 (비기술 사용자 대상)
- 매핑 오류 시 `mapping.json` 파일 자동 열기
- 진행 상태 실시간 표시

### 3. 데이터 무결성
- 라이더명이 비어있는 행은 자동으로 건너뜀 (None 처리)
- 병합 셀 자동 감지 및 올바른 위치에 입력
- 수식 보존 (data_only=False)

### 4. 크로스 플랫폼 지원
- Windows, macOS, Linux 지원
- Windows 실행 파일(.exe) 배포 지원 (PyInstaller)

## 🎯 유사 업무 자동화 프로그램 아이디어 제시를 위한 핵심 포인트

이 프로젝트의 핵심은 **"Excel 파일 간의 복잡한 데이터 매핑을 설정 파일로 관리하는 자동화 도구"**입니다.

### 핵심 패턴
1. **소스 → 타겟 매핑**: 한 Excel 파일에서 다른 Excel 파일로 데이터 변환
2. **다양한 변환 로직**: 단순 복사, 조건부 처리, 계산, 집계 등
3. **설정 기반 확장성**: 코드 수정 없이 JSON 설정으로 규칙 추가
4. **주기적 반복 작업**: 주차별, 월별 등 주기적으로 반복되는 작업

### 적용 가능한 업무 영역
- 정산/회계 업무: 다양한 정산서, 급여명세서, 세금계산서 등
- 리포트 생성: 원본 데이터를 다양한 양식의 리포트로 변환
- 데이터 마이그레이션: 구 시스템 데이터를 신 시스템 양식으로 변환
- 집계 및 분석: 여러 시트/파일의 데이터를 하나로 집계

### 기술적 특징
- Excel 파일 처리 (openpyxl)
- GUI 도구 (PySide6)
- 설정 기반 아키텍처 (JSON)
- Strategy 패턴으로 확장 가능한 계산 로직
