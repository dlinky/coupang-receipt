# 본사 정산서 자동화 프로그램 PRD 작성 요청

## 프로젝트 개요
본사에서 내려온 정산서(엑셀 파일)의 데이터를 지점 양식에 맞게 자동으로 매핑하여 입력하는 데스크톱 애플리케이션을 개발합니다.

## 기술 스택
- Python
- PySide6 (GUI)
- openpyxl 또는 xlwings (엑셀 파일 처리)

## 핵심 기능 요구사항

### 1. 파일 처리 기능
- 본사 정산서 엑셀 파일 로드 (비밀번호 보호된 파일 지원)
- 지점 정산서 엑셀 파일 로드
- 데이터 매핑 후 지점 정산서 저장

### 2. 데이터 매핑 시스템
**매핑 정보 구조:**
- 데이터 이름 (예: "라이더 목록", "프로모션" 등)
- 지점 파일 시트명
- 지점 파일 셀 범위
- 본사 파일 시트명
- 본사 파일 셀 범위
- 계산/변환 방식 (단순복사, 조건부복사, 날짜계산, 고유값추출 등)

**매핑 관리 기능:**
- 매핑 정보를 JSON 또는 YAML 파일로 저장/로드
- GUI에서 매핑 정보 수정 가능

### 3. 병합 셀 처리
- 데이터 입력 시 대상 셀이 병합된 셀인지 자동 감지
- 병합 셀인 경우: 병합 영역의 첫 번째 셀에 값 입력
- 일반 셀인 경우: 직접 값 입력

### 4. 파일 구조 및 네이밍
**본사 정산서:**
- 파일명 형식: `빅보스_부산_진구중앙_YYYY_MM-W.xlsx`
  - YYYY: 연도
  - MM: 월
  - W: 주차 (1~5)
- 비밀번호 보호 파일

**지점 정산서:**
- 파일명 형식: `쿠팡 MM월 W주차 정산표.xlsx`
- 본사 파일의 연월주 정보를 파싱하여 자동 생성

## 상세 데이터 매핑 요구사항

### [주간정산 시트] 1주차 기준 매핑

#### 단순 복사 항목:
1. **라이더 목록** (C6:C35)
   - 원본: 본사 파일 '종합' 시트 C17:C46

2. **고용보험** (T6:T35)
   - 원본: 본사 파일 '종합' 시트 AE17:AE46

3. **시간제보험** (X6:X35)
   - 원본: 본사 파일 '종합' 시트 AH17:AH46

4. **보험료 소급** (Y6:Y35)
   - 원본: 본사 파일 '종합' 시트 AI17:AI46

5. **공급가** (AJ4)
   - 원본: 본사 파일 '종합' 시트 B10

6. **부가세** (AJ5)
   - 원본: 본사 파일 '종합' 시트 C10

7. **관리비** (AJ21)
   - 원본: 본사 파일 '종합' 시트 B6

#### 조건부 처리 항목:
8. **프로모션** (E6:E35)
   - 원본: 본사 파일 '협력사 자제 미션' 시트
   - 로직:
     - G열 9행 이하에서 라이더 이름 확인
     - F열에서 프로모션 금액 확인
     - J열에서 달성 여부 확인
     - 달성한 라이더만 프로모션 금액을 지점 파일에 입력

#### 날짜/텍스트 계산 항목:
9. **기사별 정산 내역 타이틀** (B2)
   - 형식: `기사별 정산 내역(MM월 W주차)`
   - 본사 파일명에서 월/주차 정보 파싱

10. **익일정산 신청 내역 타이틀** (AB2)
    - 형식: `익일정산 신청 내역(MM월 W주차)`

11. **지점 정산서 타이틀** (AI2)
    - 형식: `지점 정산서(MM월 W주차)`

12. **기사별 정산서 타이틀** (AL2)
    - 형식: `쿠팡 MM월 W주차 정산서\n(MM.DD ~ MM.DD)`
    - 날짜 계산: 전주 수요일 ~ 해당주 화요일

13. **지급일자** (AM6)
    - 형식: `YY.MM.DD`
    - 날짜 계산: 해당 주차의 금요일

### [주간정산 시트] 주차별 오프셋 처리
- 1주차: 기준 위치
- 2주차: 행 방향 +36 오프셋
- 3주차: 행 방향 +72 오프셋
- 4주차: 행 방향 +108 오프셋
- 5주차: 행 방향 +144 오프셋

본사 파일과 지점 파일 모두 동일한 오프셋 규칙 적용

### [월간정산 시트]
14. **라이더 목록** (C6:C35)
    - 원본: 지점 파일 '주간정산' 시트의 모든 주차 라이더 목록
    - 로직: 전체 주차 라이더 중복 제거 후 고유값만 추출

## GUI 요구사항 (PySide6)

### 메인 창
- 본사 파일 선택 버튼 + 경로 표시
- 본사 파일 비밀번호 입력 필드
- 지점 파일 선택 버튼 + 경로 표시 (또는 자동 생성 옵션)
- 주차 선택 (1~5주차 또는 전체)
- "데이터 매핑 실행" 버튼
- "매핑 설정 수정" 버튼 (매핑 수정 창 열기)
- 진행 상태 표시 (프로그레스 바 + 로그)

### 매핑 수정 창
- 매핑 항목 리스트 (테이블 뷰)
  - 데이터 이름
  - 지점 시트명/셀범위
  - 본사 시트명/셀범위
  - 계산 방식
- 매핑 항목 추가/수정/삭제 버튼
- 매핑 설정 저장 버튼

## 에러 처리
- 파일 열기 실패 (비밀번호 오류, 파일 없음)
- 시트명/셀범위 오류
- 데이터 타입 불일치
- 모든 에러는 GUI에 사용자 친화적 메시지로 표시

## 확장성 고려사항
- 새로운 데이터 매핑 항목을 코드 수정 없이 추가 가능하도록 설계
- 다양한 계산 방식을 플러그인처럼 추가할 수 있는 구조

위 요구사항을 바탕으로 상세한 PRD를 작성해주세요.
